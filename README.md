# Personal Portfolio Website Template

A clean, modern, and responsive personal portfolio website template built with **HTML, CSS, and JavaScript**.

This template is mainly designed for **students, developers, and beginners** who want to create a professional portfolio website without using any framework or complex setup.

## Features

* Responsive design
* Modern and clean UI
* Smooth animations and interactions
* Dark/Light mode
* About Me section
* Skills section
* Projects section
* Education section
* Contact section
* Social media links
* No frameworks or npm required

## Project Structure

```text
Protfolio/
├── CSS/
│   └── style.css
├── JS/
│   └── script.js
└── index.html
```

## How to Use

### 1. Download or Clone the Repository

You can either download the ZIP file or clone the repository using Git:

```bash
git clone https://github.com/adarshyadav074/Protfolio-Website-For-Students.git
```

You can also open the repository directly:

https://github.com/adarshyadav074/Protfolio-Website-For-Students

### 2. Customize the Website Using AI

This template is designed to make customization easy.

Open the existing `index.html` file and upload it to any AI chatbot such as **ChatGPT, Claude, Gemini, or another coding AI**.

Give the AI your personal information, such as:

* Full name
* Short introduction
* Location
* Education
* College/University
* Course and branch
* Skills
* Projects
* Achievements
* Certifications
* Experience
* Social media profiles
* GitHub profile
* LinkedIn profile
* Email
* Any other information you want to display

You can simply ask the AI to customize the existing portfolio using your information while keeping the same design and functionality.

### 3. Replace `index.html`

After the AI generates the customized code:

1. Copy the generated `index.html` code.
2. Replace the existing `index.html` with the new code.
3. Keep the `CSS` and `JS` folders unchanged unless you specifically want to modify the design or functionality.

Your folder structure should remain:

```text
Protfolio/
├── CSS/
│   └── style.css
├── JS/
│   └── script.js
└── index.html
```

### 4. Test Your Website

Open `index.html` in your browser and check:

* All sections
* Navigation
* Animations
* Dark/Light mode
* Project links
* Social media links
* Contact information
* Mobile responsiveness

If something doesn't work, ask an AI coding assistant to identify and fix the issue.

### 5. Publish Your Portfolio

Once everything looks good, you can publish your website using platforms such as:

* GitHub Pages
* Vercel
* Netlify
* Any static website hosting service

Since this is a static HTML/CSS/JavaScript website, no backend or server setup is required.
