# 🚀 Personal Portfolio Template

A modern, responsive portfolio template built with **HTML, CSS, and JavaScript**.

You don't need to manually edit the entire code. You can use **ChatGPT + Gemini Pro (Extended)** to customize this template with your own details.

## 🛠️ How to Customize

### Step 1 — Download the Template

Download or clone this repository and locate:

`index.html`

This file contains the complete portfolio website.

### Step 2 — Tell ChatGPT About Yourself

Open ChatGPT and tell it that you want to customize a portfolio template.

Give it your details such as:

- Name
- About Me
- Location
- Education / College
- Skills
- Projects
- GitHub
- LinkedIn
- Instagram
- Email
- Phone number (optional)
- Interests
- Career goal

Then ask:

> "Using my details, write a detailed prompt for an AI coding assistant to customize my existing portfolio template. Tell it to replace the template information with my details without changing the original design, animations, responsiveness, or functionality."

ChatGPT will generate a customization prompt for you.

### Step 3 — Open Gemini Pro (Extended)

Open **Gemini Pro with Extended Thinking** and start a new chat.

Upload your:

`index.html`

Then paste the customization prompt generated by ChatGPT.

Tell Gemini:

> "Here is my existing portfolio template. Follow the prompt and rewrite the complete index.html using my details. Preserve the original UI, animations, responsive design, particle background, and functionality. Return the complete updated code, not partial snippets."

### Step 4 — Replace the Code

Gemini will generate your personalized `index.html`.

Copy the complete generated code and replace the old code inside your `index.html`.

Save the file.

### Step 5 — Test Your Portfolio

Open `index.html` in your browser and check:

- Your name and About section
- Skills
- Projects
- Education
- Social links
- Email and phone links
- Mobile layout

If something needs changing, take a screenshot and send it to ChatGPT or Gemini with a description of what you want fixed.

## 💡 Easy Workflow

`Download Template → Give Details to ChatGPT → Generate Customization Prompt → Upload index.html to Gemini Pro (Extended) → Paste Prompt → Get Personalized Code → Done`

## ⚠️ Before Publishing

Make sure you replace all example information and test every social/contact link.

Only add information such as your **phone number, email, and location** if you're comfortable making it public.
